# DM Motion reel format (standing rules, from 2026-11-02)
1. ASK FIRST: open with a question the viewer can try to answer, 3-2-1 countdown, rings where the eye wanders.
2. REVEAL the real problem (must be something the audience genuinely needs to find - vet it; no made-up problems).
3. CUTAWAY scene (animated, scenes.py: desk / jury / sunarc / scroll / tape) paints the predicament, then back to the drawing.
4. SOLVE visually (scan bar applies the fix), then honest price, then CTA.
5. Something moves the entire time. Rotate palettes (green / blue / graphite-gray / light blue-white / cream); no orange.
6. HARD RULE: everything centered, fully in frame (engine2.fit_cam). Captions: glass card, accent word.
7. Voiceover wording: simple sheets "for thirty dollars" (tiers are $30/$60/$100) - never overpromise.
Tools: story_q.py <key> <name>; scenes.py; compose.py (overlay scenes on any base reel).
